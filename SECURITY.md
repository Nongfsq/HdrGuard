# Security Policy

## Supported versions

Security fixes target the latest released version of HdrGuard.

## Reporting a vulnerability

Do not post private logs, credentials, device identifiers, or unredacted network details
in a public issue. Open a GitHub security advisory or contact the maintainer privately
through the repository owner profile.

Please include:

- HdrGuard version.
- Windows version.
- RustDesk version.
- A minimal description of the issue.
- Redacted logs only if they are required to reproduce the problem.
